## 0. 원칙 (모든 항목에 적용)

1. **저작권**: 벤치마크 대상은 *구조·흐름·화면 구성 방식*뿐이다. 아래는 가져오지 않는다.
   - 픽셀아트 화풍 → 우리는 기존 SVG 벡터 + My Koala 화풍 유지
   - 원작 캐릭터(로봇 도우미 Mark, 주인공, 주민), 스토리 요소(42, 유령, 촉수, 로켓)
   - 원작 UI 문구·카드 디자인("Client Satisfaction Feedback" 등), 마을 배치, 개별 가구 디자인
   - 원작 스크린샷·영상 파일은 저장소에 넣지 않는다 (참고는 Steam 페이지 링크로만).
2. **어린이 대상**: 으스스한 요소 금지. 이모지·아이콘은 실제 의미를 확인하고 사용한다(CLAUDE.md 금지 목록 준수).
3. **모바일 우선**: 390px 폭이 기준. 태블릿(서피스)·데스크탑도 확인한다.
4. **무료/프리미엄 차이**를 항목마다 명시한다. 2D(스티커)는 일반, 3D(팝아웃)는 프리미엄 규칙 유지.
5. **코인 규칙**: 코인이 빨리 쌓이지 않게 한다. 부탁 보상은 코인보다 *가구 세트·장식*을 우선한다.
6. 소리를 쓰면 기존 `public/js/asmr-sound.js` 체계를 재사용하고, 소리·자원 변경 시 `sw.js` 버전을 올린다.

## 2. 현재 My Koala 구조 (2026-10-28, v259 기준)

- 렌더링: 전부 SVG. 타일 64×32(`TW/TH`), 벽 높이 150px, `proj(x,y,z)` 등각 투영. 가구는 박스/원기둥/구/피라미드 파츠(`B/C/S/PY`) 또는 매니페스트 이미지(`public/img/house/README.md`).
- 아이템 정의: `{ id, cat, name:[ko,en], w, d, parts, price, flat, stack, topH, where, only, tiers }`. 벽 장식은 `wd()`(벽 평면 px 단위).
- 방 종류 `ROOMS`: study(무료)·bedroom·master·living·kitchen·playroom·cinema·bath·garage — 모두 **직사각형 C×R**.
- 평면도 `PLAN = 3×3` 슬롯(`s0..s8`), 시작 슬롯 `s7`. 마당(`yard`: 집 외관 스타일·정원 프리셋·테두리·길).
- 상태 저장: `localStorage` `koalaHouse:v2` (`v:2, cur, owned, walls, floors, houseStyles, yardSizes, slots{}, yard{}`), v1 마이그레이션 존재.
- 편집 화면 레이아웃(`koala-house.css`): `.kh-stage`(방) + `.kh-panel`(목록, 데스크탑 `min(540px,44vw)`), 세로 화면·좁은 폭에서는 위아래로 나뉨(방 `min(58vh,520px)` + 목록).
- 되팔기 80%(수수료 20%), 관리자/무제한(`curOpts.unlimited`) 처리 있음. 3D는 `canUsePaidFeatures()`로 구분.

## 3. 적용 항목 (우선순위 순)

각 항목: 목표 / 화면 / 데이터·코드 변경 / 무료·프리미엄 / 완료 기준.

### P1. 방 전체 화면 + 떠 있는 목록 패널 ★ 첫 시안 대상
- **목표**: "화면을 넓게 쓰는 느낌". 방이 화면을 꽉 채우고 목록은 겹쳐 뜬다.
- **화면**
  - 데스크탑·태블릿 가로: 방 100% 폭. 오른쪽에 떠 있는 패널(폭 약 280~320px, 둥근 모서리, 부드러운 그림자). 접기 버튼으로 숨기면 방만 보임.
  - 모바일·세로: 아래에서 올라오는 **서랍(bottom sheet)**. 접힌 상태 = 카테고리 아이콘 한 줄(높이 약 64px), 펼친 상태 = 화면 약 45%. 끌어 올리고 내리기.
  - 카테고리 줄은 한 줄 + 넘치면 화살표 버튼(CLAUDE.md 규칙).
  - 칸마다 보유 개수 배지(×2), 길게 누르기/마우스 올리기로 이름표.
  - 테마 배경: 방 종류별 낙서 무늬(주방=식기, 공부방=연필·책…) SVG 패턴을 스테이지 배경에. 방은 가운데 떠 있는 디오라마로.
- **코드**
  - `koala-house.css`: `.kh-room-screen`을 flex 분할 → `position:relative` 스테이지 + `position:absolute` 패널(데스크탑) / `position:fixed` bottom sheet(모바일)로 변경. 기존 `.kh-narrow`, `@media (max-width:760px)` 규칙 정리.
  - `koala-house-ui.js`: `drawPanel()`에 접기/펼치기 상태(`ses.panelOpen`), 시트 드래그 핸들, 패널 열림 시 스테이지 `fit()` 재계산(가려지는 영역만큼 방을 옮김).
  - `koala-house.js`: `ROOMS[*].bg`(배경 패턴 키) 추가, 패턴 SVG 생성 함수.
- **무료/프리미엄**: 동일.
- **완료 기준**: 390/768/1280 폭에서 방이 화면의 70% 이상 보임. 끌어서 놓기·메뉴·코알라 이동이 기존과 같이 동작. 패널을 접었을 때 방 전체가 보임.

### P2. 배치 피드백 (초록/빨강 외곽선)
- 끌고 있는 동안 놓을 수 있으면 초록 외곽선, 겹치거나 벽 밖이면 빨간 외곽선 + ⊘.
- **코드**: `updateDrag()`에서 이미 계산하는 충돌 결과를 고스트(`ghostFor`)의 클래스(`is-ok`/`is-bad`)로 노출, CSS `filter: drop-shadow` 외곽선.
- **완료 기준**: 모든 방·마당에서 불가 위치는 빨강, 놓으면 원위치 복귀.

### P3. 색·재질 팔레트
- 벽·바닥·일부 가구를 누르면 작은 팝업: 재질 3~4종 + 색 칩 12~24개(어린이용으로 원작보다 적게, 크게).
- **코드**: 가구 정의에 `tint:true` 플래그, 배치 항목에 `col` 필드 → 렌더 시 `faces(col)` 사용(이미 `shade()` 체계 있음). 이미지 가구는 SVG `feColorMatrix` 필터 또는 색 변형 이미지가 있을 때만 지원.
- **무료/프리미엄**: 무료 = 기본 색 6개, 프리미엄 = 전체 팔레트(안). 사용자 결정 필요.
- **데이터**: 아이템 인스턴스에 `col` 추가는 하위 호환(없으면 기본색). 저장 버전 유지 가능.

### P4. 동물 친구 부탁 + 평가 카드 (게임 루프)
- **목표**: 자유 꾸미기에 "목표"를 준다.
- **흐름**: 부탁 받기(그림 말풍선) → 방 꾸미기/정리/청소 → "다 했어요" → **평가 카드**(완성 방 썸네일, 별 1~3개, 도장 연출, 친구의 한마디, 보상) → 보상 획득 알림.
- **부탁 종류**
  1. 자유형: "아늑한 침실을 만들어 줘" — 필수 카테고리 개수만 검사(침대 1, 조명 1…)
  2. 지정형: "침대는 창가에" — 위치 조건 검사(벽 인접, 특정 아이템 옆)
  3. 정리형: 상자에서 물건을 하나씩 꺼내 놓기(P6과 연결)
  4. 청소형: 쓰레기를 휴지통으로 끌기, 먼지 문지르기(ASMR 소리)
- **데이터**: `public/js/koala-house-quests.js`(신규) — `QUESTS = [{ id, friend, room, kind, need:[조건], reward:{ set, coins }, unlock }]`. 상태 `S.quests = { done:{id:stars}, active:id }`.
- **보상**: 기본은 친구의 가구 세트(그 부탁에서만 얻는 아이템) + 소량 코인. 같은 부탁 반복 보상 없음(코인 악용 방지).
- **캐릭터**: 원작 대신 호주 동물 친구(웜뱃, 캥거루, 웃는물총새 쿠카부라, 오리너구리 등). 그림은 Canva로 제작(CLAUDE.md "My Koala 아이콘은 Canva").
- **무료/프리미엄**: 무료 = 기본 부탁 몇 개, 프리미엄 = 전체 부탁·특별 세트(안). 사용자 결정 필요.

### P5. 코알라 마을 지도 (확장 무대)
- **목표**: 방 → 집 → 마당 → **마을**로 무대를 넓힌다.
- **화면**: 등각 마을 지도(가로 스크롤/드래그 이동, 모바일은 핀치 줌). 건물 = 내 집 + 친구 집 + 가게. 건물 위 **아이콘 말풍선**(🏠 내 집, 부탁 있음, 완료). 잠긴 구역은 구름/공사 울타리로 가리고 코인·부탁 완료로 열기.
- **구역 안**: 1단계 = 중심가(내 집, 친구 집 2~3채), 이후 해변·공원·학교 등 테마 구역 추가. 계절·날씨·밤은 오버레이로(P8).
- **코드**: `koala-house.js`에 `TOWN = { lots:[{ id, kind:"home|friend|shop", c, r, w, d, building, unlock }] }`, 렌더는 기존 `proj()`·박스 파츠 재사용. 화면 전환: 평면도 ↔ 마을(줌 아웃) 전환 애니메이션.
- **데이터**: `S.town = { unlocked:{}, ... }` → 저장 구조 변경이므로 `koalaHouse:v3` + v2 마이그레이션.
- **무료/프리미엄**: 무료 = 중심가, 프리미엄 = 추가 구역(안).

### P6. 이삿짐 상자 모드 (모바일 친화 배치 방식)
- 부탁(정리형)이나 새 방에서, 화면 구석의 상자를 누르면 물건이 **하나씩** 나온다 → 끌어서 배치. 목록 패널 없이 꾸밀 수 있어 모바일 화면을 가장 넓게 씀.
- **코드**: `ses.box = [id…]` 큐, 다음 아이템 미리보기, 기존 `placeNew()`·드래그 재사용.

### P7. 층·복층·방 모양
- 1단계: **ㄱ자 방** — 방 정의에 `mask`(제외할 타일 목록) 추가, 바닥·벽 그리기와 충돌 검사에서 제외.
- 2단계: **층 전환(1F/2F)** — 슬롯에 `floors:[{items}]`, 편집기 오른쪽 아래 층 버튼, 계단 아이템이 층 연결.
- 3단계: **다락(경사 지붕)·옥상·발코니** — 외관(마당) 쪽 확장.
- 저장 구조 변경 → v3 마이그레이션에 함께 포함.

### P8. 분위기 연출
- 창문 햇빛 줄기(반투명 다각형), 낮/저녁/밤 색 오버레이, 마을 눈·비 파티클(CSS 애니메이션, `prefers-reduced-motion` 존중).
- 테마 배경 패턴(P1과 공유).

### P9. 반응하는 가구 + 보관함
- 누르면 반응: 애니메이션(흔들림·빛) + 소리(`asmr-sound.js` 재사용) + 이모지 말풍선(의미 확인한 이모지만).
- 아이템 정의에 `react:{ anim, sound, bubble }`.
- 보관함: 옷장·상자 클릭 → 3×3 칸 팝업, 작은 물건 넣기(`i.store=[ids]`). 기존 `sub`(선반 위 물건) 체계와 겹치지 않게 설계.

### P10. 획득 알림·화면 전환
- "새 가구를 얻었어요!" 토스트(기존 `toast()` 확장, 아이템 그림 포함).
- 평면도 ↔ 방 ↔ 마을 이동 시 동그라미 오므리기/펼치기 전환(CSS `clip-path`).

## 4. 단계별 일정 (제안)

| 단계 | 내용 | 저장 구조 변경 |
|---|---|---|
| 1 | P1 전체 화면 + 떠 있는 패널, P2 배치 피드백, P10 알림 | 없음 |

## 7. 테스트 계획

- `browser-test` 스킬(`.claude/skills/browser-test`)로 로컬 서버(`npx wrangler dev --port 8787`, 로컬 DB)에서 확인.
- 폭: 모바일 390, 태블릿(서피스 약 912), 데스크탑 1280 이상.
- 계정: 관리자(잠금 없음) / 무료 / 프리미엄.
- 확인 항목: 방이 보이는 비율, 끌어 놓기, 패널 접기·펼치기, 코알라 이동, 되팔기 80%, 저장·새로고침 후 유지, v2 → v3 마이그레이션(기존 저장 데이터 손실 없음), 다크/라이트, 콘솔 오류 없음.
