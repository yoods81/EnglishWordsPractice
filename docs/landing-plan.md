# 첫 화면 랜딩 분리 — 논의 정리 (2026-11-22)

뮤즈 혼합안(안심 → 한 문제 맛보기 → 리포트 샘플 → 가격 → 시작 버튼)을 바탕으로, 사이트 규칙과 실제 기능에 맞춰 고친 시안 2개.

## 시안
- **L1 혼합안 수정판:** 히어로 → 안전 문구 → 한 문제 맛보기 → 사용법 3단계 → 주간 리포트 샘플 → 가격 2칸 → 시작 버튼. 휴대폰에서 길다(약 4.5화면).
- **L2 짧은 버전:** 데스크탑은 히어로와 맛보기를 나란히, 그 아래 특징 3칸(리포트는 "샘플 보기" 링크) → 가격 → 시작 버튼. 휴대폰 약 3화면.

## 뮤즈 목업에서 고친 점
- "No ads / No chat" 알약 → 체크 표시 글자(버튼 아닌 것에 알약 금지).
- 학년 칩 4개 알약 → **평면 탭 2개 Years 3–4 / Years 5–6**(민트 바 + 선택만 채움).
- 맛보기의 "+10 coins / Streak 3" 삭제 — 비회원에게는 코인·연속 기록이 없다.
- 리포트 샘플은 실제 이메일 항목(학습한 날·문제 수·정답률·연속 학습·완료 단어·모드별·어려운 단어)과 같게, 발송은 **월요일**(일요일 아님), "Sample" 표시.
- 무료 범위는 회원 기준 하루 100문제(비회원 30)로 정확히.
- 후기 구간은 실제 후기 2개가 모일 때까지 넣지 않는다.

## 결정 (2026-11-22) — 적용함 (sw v294)
L2, A(처음 온 비회원만), Start free = 가입 없이 바로 앱. 맛보기 단어 friend / grateful, 한국어 화면도 랜딩. 구현: `public/js/intro.js`, `public/css/intro.css`, index.html의 `#intro`와 `<head>` 판단 스크립트.

## (원래) 정해야 할 것
1. **L1 / L2** 중 어느 시안?
2. **누구에게 랜딩을 보여 줄까**
   - A (추천): 로그인 안 했고 **이 기기에서 처음 온 사람만** 랜딩. 맛보기나 "Start free"를 누르면 앱으로 가고 기기에 기록 → 다음부터는 바로 앱. 회원은 늘 바로 앱. 주소는 `/` 그대로(북마크·홈 화면 앱 안전).
   - B: 비회원은 **매번** 랜딩(재방문 비회원은 한 번 더 눌러야 함).
   - C: 랜딩을 별도 주소(`/welcome`)로 만들고 광고·홍보 링크만 그쪽으로. 앱은 그대로.
3. **"Start free" 버튼이 어디로?** ① 가입 없이 바로 앱(비회원 30문제, 추천 — 문턱이 낮음) ② 무료 가입창.
4. **맛보기 첫 단어**(학년별 고정, 쉬운 단어): Years 3–4 `friend`, Years 5–6 `grateful` — 바꾸고 싶으면 지정. 맛보기에서 고른 학년은 앱 레벨로 그대로 넘긴다.
5. **한국어 화면**도 랜딩을 보여 줄지(같은 구성을 한국어로) — 기본은 "예".
