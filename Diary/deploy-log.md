## 2026-10-22 — My Koala 아이템 관리 시스템 (관리자용) 1차 배포

### 배경
관리자가 "마이 코알라" 화면에서 코드 수정·배포 없이 새 카테고리·새 아이템을 추가할 수 있게 해달라는 요청.

### 설계 핵심 결정
- 기존 ~250개 아이템(`koala-core.js`의 `ITEMS`, `koala-house.js`의 `D`)은 **한 글자도 안 건드림**. House 일부 아이템은 `parts` 대신 SVG를 그리는 함수(코드)를 들고 있어서 DB 행으로 옮기는 게 불가능했고, 책장/액자/장난감상자 등은 "안에 하위 아이템 고르기" 메타데이터가 있어 이관 중 하나라도 빠뜨리면 조용히 깨질 위험이 컸음.
- 그래서 **D1 DB(`items`, `item_categories` 테이블)에는 관리자가 새로 만든 아이템만 들어가고**, 프런트는 이 DB 아이템을 기존 하드코딩 카탈로그 위에 "추가(merge)"만 함 — 교체 아님.
- House 아이템은 기존에 이미 있던 `/img/house/manifest.json` 이미지 교체 메커니즘을 그대로 재사용(새 드로잉 코드 불필요).
- 캐릭터/스터디룸 새 아이템은 2D 스티커용 사진 + 3D 팝아웃용 사진을 각각 업로드받음(품질 차등 유지).

### 바뀐 파일
- `migrations/0014_koala_items.sql` (신규 — D1 스키마, 원격 적용 완료)
- `worker/index.js` — 공개 조회 API(`/api/items`, `/api/item-categories`, `/api/items/manifest`, `/api/items/image/:key`) + 관리자 CRUD(`/api/admin/items*`, `/api/admin/item-categories*`) + 이미지 업로드(R2)
- `wrangler.jsonc` — R2 바인딩(`ITEM_IMAGES` → 버킷 `koala-study-mate-items`, 원격 버킷 생성 완료)
- `public/js/koala-core.js` — `loadItems()` 등 추가 로더(캐릭터/스터디룸 병합)
- `public/js/koala-house.js` — `loadCatalog()` 추가 로더(House 병합)
- `public/js/koala-art.js` — `registerCustomItem()`: 관리자 아이템을 기존 `ART`/`ROOM_ART` 테이블에 끼워 넣어 렌더링(슬롯별 범용 배치 박스 사용)
- `public/js/koala-house-ui.js` — 카테고리 탭·manifest에 관리자 데이터 병합, 관리자 전용 "+" 버튼
- `public/js/koala-admin-items.js` (신규) — 카테고리 추가 / 아이템 추가·수정 공용 모달
- `public/js/app.js` — 관리자 진입점(카테고리 "+", "+ 아이템 추가", 아이템 상세팝업 "✏️ 수정"), 로더 부트스트랩
- `public/css/style.css`, `public/css/koala-house.css` — 관리자 UI 스타일
- `public/sw.js` — v193
- `package.json` — `db:migrate:items`(:local) 스크립트

### 배포 상태
- 코드 배포 완료(2026-10-22), 원격 D1 마이그레이션 적용 완료, 원격 R2 버킷(`koala-study-mate-items`) 생성 완료.
- 로컬에서 관리자 세션을 직접 만들어 생성/중복거부/수정/비활성화/카테고리추가/이미지 업로드→R2→서빙까지 API 레벨로 전부 확인함.
- **실제 브라우저로는 아직 열어보지 않음** — 다음에 로그인해서 캐릭터/스터디룸/House 화면에서 버튼이 제대로 보이고 눌리는지 꼭 확인할 것.

### 알려진 제한사항 / 남은 과제
1. **House 아이템 수정 버튼 없음** — 추가만 가능. House 상점엔 캐릭터 화면 같은 "탭하면 상세팝업" 구조가 없어서 수정 진입점을 어디에 둘지부터 다시 봐야 함.
2. **새 캐릭터/스터디룸 아이템은 프리미엄 3D 팝아웃 전용 옷장(`KSLOT`/`KBOX`/`K3` 시스템)에 안 나옴** — 그 시스템은 아이템마다 사람이 손으로 좌표를 맞춘 표라 자동화가 안 됨. 3D용 사진은 DB에 저장은 되어 있어서(`image_key`) 나중에 연결 가능.
3. 관리자가 새로 만든 아이템에는 서브아이템 선택 기능(책장 속 책 고르기 등)이 없음 — 의도적 범위 제외.
4. 관리자 폼의 unlock 방식은 "무료/코인"만 지원(스트릭/뱃지 조건은 백엔드는 가능하나 폼 UI 생략) — 필요해지면 폼에 추가.
5. 로컬 테스트용 `.dev.vars`(SESSION_SECRET 더미값)를 만들어 둠 — gitignore 대상이라 git에는 안 올라감, 다른 컴퓨터에서 로컬 테스트하려면 똑같이 하나 만들어야 함.

## 2026-10-22 (2차) — My Koala 관리자 도구 보강 (3D 옷장 · 삭제 · 배경 제거) + 브라우저 테스트 체계

### 배경
1차 배포 후 실제로 써 보니 ① 3D 옷장(Pop-out)의 카테고리 "+" 버튼이 안 눌리고 "+ 아이템 추가"가 없었고, ② 삭제 기능이 없었고, ③ 새 아이템이 3D 옷장에 안 나왔음. 이를 순서대로 해결.

### 원인과 해결
- **3D 옷장 버튼 미동작**: 관리자 버튼 연결을 3D 집(`drawPanel`)에만 넣고 3D 옷장(`mountWardrobe`)에는 빠뜨렸음. 연결 추가. 저장되는 카테고리 이름이 3D 부위명(hat 등)이 되지 않도록 2D 슬롯명(headwear 등)으로 변환(`WARD_TO_2D`).
- **3D 옷장에 새 아이템 표시**: 3D 그림 + 저장된 위치(`fit`)가 있는 관리자 아이템을 옷장 표(`KSLOT`/`KNAME`/`KBOX`/`KORDER`/`KBEHIND`)에 합쳐 넣는 `syncCustomWard()` 추가. 서 있는 모습·앉은 모습 공용 위치표를 쓰므로 둘 다 적용됨.
- **착용 위치 자동 보정 + 슬라이더**: 그림을 올리면 투명 여백을 자동으로 잘라 내고, 부위별 기본 위치(기존 아이템 ~50개의 실제 위치 중앙값으로 보정)에 맞춰 코알라 위에 미리보기. 좌우/위아래/크기 슬라이더와 "자동 위치로 되돌리기". 위치는 `items.fit_json`(마이그레이션 `0015_item_fit.sql`)에 저장.
- **삭제**: 아이템 삭제(DB 행 + R2 그림 삭제, 이미 산 사용자 목록에서도 사라짐, 환불 없음)와 카테고리 삭제(안에 아이템이 있으면 409로 거부). 진입점: 2D "✏️ 수정" 창, House 상세 팝업, 3D 옷장 상세 팝업(수정·삭제 버튼). 3D 옷장 상세에는 처음에 빠뜨렸다가 사용자 지적 후 추가.
- **House 새 아이템이 회색 상자로 보이던 버그**: 그림 목록(manifest)을 마운트 때 한 번만 받아서 생긴 문제. 아이템 저장 직후 다시 받도록 수정.
- **배경 자동 제거**: 사용자가 올린 "배경 제거" 그림에 체크무늬가 불투명 픽셀로 박혀 있던 문제. 업로드 시 진짜 투명 픽셀이 있는지 검사 → 없으면 경고 + "그림 배경 자동 지우기" 자동 켬. 가장자리 색(체크무늬는 두 색)을 배경으로 보고 안쪽으로 채워 지움(안쪽에 둘러싸인 흰 부분은 유지, 경계는 부드럽게). 3D 미리보기에 바로 반영, 체크로 끄기 가능. 2D 그림·House 그림에도 적용(크기는 자르지 않음).

### 바뀐 파일
- `migrations/0015_item_fit.sql` (신규), `package.json`(`db:migrate:item-fit`)
- `worker/index.js` — `fit` 저장·검증(`parseFit`), `DELETE /api/admin/items/:id`, `DELETE /api/admin/item-categories/:kind/:id`

## 2026-10-22~23 (3차) — 관리자 도구 마무리(2D/3D 분리·위치 조절·배경 제거) + 3D 방꾸미기 배치 보정 + ASMR 에셋

### 관리자 도구 (v195~v200)
- **탭별 폼 분리**: Sticker(2D) 탭 = 2D 그림 입력·미리보기만, Pop-out(3D) 탭 = 3D 그림 입력·코알라 위치 미리보기만. 2D 탭에서 만든 아이템은 3D 옷장에, 3D 탭에서 만든 아이템은 2D 목록·My items에 안 나옴(`no2d` 플래그).
- **3D 옷장에도 수정·삭제 버튼**(상세 팝업), 2D 상세 팝업에도 "🗑 삭제" 직접 노출. 아이템 추가 직후 카드에 그림이 안 뜨던 버그(2D 그림 등록 누락) 수정.
- **2D 자동 위치 + 슬라이더**: 2D는 그림을 머리/전신 화면 전체에 늘려 붙이던 방식이라 투명 여백을 자른 왕관이 얼굴 한가운데로 감. 3D처럼 여백 제거 → 기존 2D 아이템 bbox 중앙값 기준 기본 위치 → 슬라이더. DB `items.fit2d_json`(마이그레이션 `0016_item_fit2d.sql`), 좌표계는 `koala-art.js` FULL_VIEW(200x205). 기존 방식 아이템은 그대로(fit2d 없으면 전체 화면 맞춤).
- **배경 자동 제거**: 체크무늬가 불투명 픽셀로 박힌 "투명" 그림 감지 → 가장자리 색(체크무늬는 두 색)에서 안쪽으로 flood fill, 안쪽에 둘러싸인 흰 부분은 유지, 경계 부드럽게. 체크로 끄기 가능. 2D·3D·House 그림 모두 적용.
- **사고**: 테스트 정리 스크립트가 로컬 DB의 모든 아이템을 지워 사용자가 만든 아이템이 사라짐(로컬 DB만, 실서버 영향 없음). `browser-test` 스킬에 `snapshot()/restore()`(자기가 만든 것만 삭제) 도입, 일괄 삭제 금지 규칙 기록.

### 3D 방꾸미기 배치 (v200~v201)
- **겹침 순서(overlay)**: 기존엔 "먼 모서리 번호" 하나로 정렬해서 침대 옆 책장·테이블 끝 의자처럼 모양이 다른 가구가 뒤바뀜. 칸(footprint) 기준 위상 정렬 `depthOrder()`로 교체(A가 B보다 완전히 뒤면 A 먼저). 가구 44종 4방향 쌍 15,488조합에서 순서 오류 1,224건 → 0건. 코알라 삽입용 `data-k`는 단조 증가로 재기록, 테이블 위 소품은 테이블 바로 뒤.
- **떠 보임(floating)**: 그림이 칸보다 작게(둥근 식탁 44%, 의자 38~44%, 장난감 상자·변기 63%, 울타리 56%) 그려진 것을 칸에 맞게 크기·바닥 위치 보정(`manifest.json`). 침대는 그림이 칸 앞 가장자리보다 4~14px 위에 떠서 머리 쪽 다리가 벽 아래 회색 띠 위로 올라와 보였음 → 앞 가장자리(R/L/B 모서리) 접촉 평균이 0이 되도록 가구 20여 종 높이 보정.
- **바닥 그림자**: 작은 타원 하나 → 가구 칸 모양의 부드러운 마름모. 긴 가구의 먼 쪽까지 바닥에 붙어 보이고 나란한 가구끼리 그림자가 이어짐.
- 정원(마당) 가구는 일부(강아지집·울타리 등)만 보정. 칸 이동·드래그 중 막힘 현상은 재현 못 함(canPlace는 칸 단위로 정확함).
